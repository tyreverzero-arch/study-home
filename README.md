# Study Hub 📚

一个**单文件**的前端学习主页（`index.html`，零依赖、零构建），可直接用浏览器打开，也可以丢进任意静态服务器 / Docker 部署。

## 功能

- 🖥️ **学习内容门户**：JS / Python / 数据库 / 计网 / Linux / AI 等技术栏目卡片，每次刷新随机换栏目、换排版、换素材
- 📖 **底部状态栏阅读器**（VS Code 风格）：
  - 支持导入 TXT 小说（自动识别 GBK / UTF-8 编码，IndexedDB 本地存储）
  - 章节解析与目录弹窗、搜索跳章
  - 多种阅读主题、字号调节
- 🪟 **悬浮阅读窗**：可拖动、可调大小、透明无边框，可融入页面任意位置
- ⌨️ **全键盘自定义快捷键**：翻页 / 跳章 / 目录 / 显隐底栏等，支持组合键录制
- 🖱️ **多种翻页方式**：左键点击翻页、滚轮上下翻页（可开关）
- 🕶️ **专注模式（老板键）**：多键位触发（Shift 单按 / 鼠标中键 / 自定义组合键），一键切换为"工作状态"，仅保留界面信息分区

## 使用

```bash
# 方式一：直接双击 index.html 用浏览器打开

# 方式二：Docker
docker run -d --name studyhub -p 8090:80 \
  -v "$PWD/index.html:/usr/share/nginx/html/index.html:ro" \
  nginx:alpine
```

所有数据（小说、设置）均保存在浏览器本地（IndexedDB + localStorage），不上传任何服务器。
